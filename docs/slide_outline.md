## 1. 封面
- 題目：精準打擊：AI 驅動的「智慧巡訪與成交預判」系統
- 挑戰事業體：中化裕民
- 隊名 / 隊員

## 2. 問題洞察（一）業務現場的真實痛點
- CRM 目前只是「事後紀錄工具」：業務員拜訪完才補登資料，缺乏事前判斷依據
- 拜訪資源分配靠經驗與人情，不是靠數據：熟客拜訪過度、風險客戶反而被忽略
- 缺乏「競品入侵」早期預警：等到訂單掉了才發現客戶已被競品滲透，為時已晚

## 3. 問題洞察（二）量化這個問題有多大
- 用一頁數據/示意圖呈現：假設全公司 X 位業務、Y 個客戶，若 10-15% 高價值客戶
  因拜訪不到位而流向競品，換算成年度營收損失是多少
- 對照「拜訪次數」與「訂單轉換」目前脫鉤的現況（可用原型 Dashboard 的散佈圖佐證）

## 4. 創新解方：把 CRM 從「紀錄工具」變成「戰略大腦」
- 核心主張：同一套客戶資料，疊加「成交機率預測」＋「異常風險偵測」＋「優先排序引擎」＋「可解釋性」
- 四個模組：
  1. **成交預判模型**：預測每位客戶未來 90 天下單機率
  2. **競品入侵風險偵測**：IsolationForest 無監督異常偵測，找出拜訪/業績/競品訊號組合異常的客戶，提前示警
  3. **每日拜訪優先清單 + 路線視覺化**：把成交機率、客戶價值、風險加權合成單一分數，排出「今天該拜訪誰、依什麼順序」
  4. **可解釋性模組**：針對單一客戶說明「系統為什麼這樣判斷」，不是黑盒子，業務主管才會信任並採用

## 5. 系統架構總覽
- 資料層：CRM 拜訪紀錄、ERP 訂單資料、客戶地理座標、（未來可加）業務員回報標籤
- 特徵工程層：RFM、業績趨勢、拜訪-訂單轉換率、競品提及次數
- 模型層：
  - RandomForest 分類模型（成交預判）
  - IsolationForest 無監督異常偵測（競品入侵風險，取代早期規則式加權）
  - 可解釋性模組：特徵重要性 × 客戶百分位 → 白話理由
- 排序引擎：w1×成交機率 + w2×客戶價值 + w3×風險 → 優先分數
- 應用層：Web Dashboard（管理總覽含地理熱點地圖 / 業務員視角含拜訪路線 / 客戶診斷含判斷理由）+ 每日通知信

## 6. 系統展示（一）：管理總覽
- 全公司客戶健康度總覽：高風險客戶數、平均成交機率、拜訪覆蓋率
- 客戶價值 × 成交機率 × 風險 三維視圖，一眼看出「該搶救誰」
- **客戶地理分佈地圖**：風險客戶是否集中在特定區域，作為人力調度參考

## 7. 系統展示（二）：業務員每日建議 + 拜訪路線
- 依優先分數自動排序的拜訪清單
- **地圖上標出建議拜訪順序**，取代純文字清單，業務員一眼就懂今天怎麼跑
- 針對每位客戶給出具體建議行動（攔截競品 / 推進成交 / 維繫關係）

## 8. 系統展示（三）：客戶診斷（含可解釋性）& 模型洞察
- 單一客戶的訂單趨勢、拜訪歷程、風險燈號
- **系統判斷原因**：白話說明「為什麼這個客戶成交機率高/低」，例如「近90天營收下滑35%，低於85%的同業客戶」
- 模型特徵重要性 + IsolationForest 異常分數分佈，讓業務主管理解「為什麼系統這樣建議」，建立信任感

## 8-1. 系統展示（四）：每日主動通知（Email + LINE）+ 可匯出報表
- 從「打開系統才看得到」升級為「系統主動推播」：每天自動寄送
  - 給每位業務員：今日建議拜訪清單（Email + LINE 訊息兩種格式）
  - 給主管：高風險客戶（疑似競品入侵）彙總信
- 業務員多在外面跑客戶，**LINE 訊息 mock** 比 email 更貼近真實使用情境，訊息內建風險燈號 emoji，一眼看懂
- 一鍵匯出 CSV / Excel，方便帶去現場或匯入其他報表系統
- 目前原型以 Dry Run 模式展示信件內容、LINE 為視覺化 mock；正式導入時設定 SMTP 帳密 / LINE Bot API 即可排程自動推播

## 8-2. 系統展示（五）：Next Best Action — 不只說去誰家，還說推什麼
- 用「同通路 × 同等級」客戶的品項採購佔比當同儕基準，找出該客戶明顯低於同儕的品項缺口
- 每個拜訪建議都附帶一句具體行動：「建議主推『OTC』——同儕客戶平均採購 19%，此客戶目前僅 0%」
- 讓業務員不只知道「去誰家」，還知道「帶什麼話術/品項去」，直接對應「毛利保衛戰」「智慧座標」等題目精神

## 9. 技術可行性與資料落地路徑
- 目前以合成資料驗證 pipeline 可行性：5-fold 交叉驗證 AUC 0.618 ± 0.023（尚有優化空間，但表現穩定、非單次抽樣運氣）
- 換上真實 CRM/ERP 歷史資料後，模型可直接重新訓練，不需改架構
- 資料需求：拜訪紀錄（時間/對象/業務員/備註）、訂單紀錄（時間/金額/品項）、客戶基本資料

## 10. 落地效益
- 效率面：減少無效拜訪，資源集中在高價值/高風險客戶 → Bootstrap 重抽樣估計顯示 Top-N 拜訪清單
  平均成交機率可由 ~54%（95% CI 52–55%）提升至 ~67%（95% CI 65–68%），提升約 +13 個百分點
  （合成資料下的統計模擬，非真實 A/B 測試，正式上線建議以同期隨機分派驗證）
- 防禦面：及早攔截競品入侵，降低客戶流失率
- 加值面：Next Best Action 讓每次拜訪不只維繫關係，還能主動擴大品項滲透，提升客單價
- 傳承面：業務離職/輪調時，客戶關係與判斷邏輯留在系統裡，不隨人走

## 11. 導入規劃（Roadmap）
- Phase 1（1-2 個月）：串接真實 CRM/ERP 資料、模型重新訓練與驗證
- Phase 2（2-3 個月）：小範圍業務團隊試點，量測拜訪效率與成交率變化
- Phase 3：全區推廣 + 加入拜訪路線規劃、話術建議等進階模組
